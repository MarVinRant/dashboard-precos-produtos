# Rascunhos de publicações

Repositório dos projetos: https://github.com/MarVinRant/dashboard-precos-produtos

## Projeto 1 - Dashboard de Preços e Produtos

Concluí a primeira etapa da minha trilha prática de Python: um dashboard de
preços e produtos com filtros por categoria e faixa de preço, métricas de ticket
médio e gráficos interativos.

Neste projeto pratiquei Python, Pandas, Plotly, Streamlit, testes e publicação
de uma aplicação. O principal aprendizado foi separar carregamento, limpeza,
regras de negócio e interface.

## Projeto 2 - Análise Exploratória

Desenvolvi uma análise exploratória reproduzível usando dados de produtos. O
projeto calcula média, mediana, desvio padrão, vendas por categoria e preço médio
por categoria, além de gerar figuras e um resumo em JSON.

Aprendi que uma boa análise começa com perguntas e validação dos dados, não com
a escolha de um gráfico.

## Projeto 3 - Estoque CRUD

Implementei um sistema de estoque com Python, SQLite e Streamlit. A aplicação
permite cadastrar, consultar, buscar, atualizar e excluir produtos, além de
alertar quando o estoque atinge o limite mínimo.

O foco foi praticar SQL parametrizado, persistência, validação e testes do ciclo
CRUD.

## Projeto 4 - API de Produtos

Criei uma API REST com FastAPI para listar, filtrar, cadastrar e excluir
produtos. A API possui validação de dados, códigos HTTP adequados e documentação
interativa em Swagger.

Esse projeto consolidou meus estudos sobre back-end, schemas, endpoints e
comunicação entre sistemas.

## Projeto 5 - Machine Learning

Implementei um modelo introdutório para estimar quantidade vendida usando preço
e categoria. Além da métrica do modelo, incluí uma previsão baseline para evitar
conclusões sem comparação.

O principal aprendizado foi entender que uma métrica precisa ser interpretada
com contexto e com as limitações da base de dados.

## Projeto 6 - Automação de Relatórios

Criei uma automação que lê dados de produtos, valida a entrada, agrupa os
resultados por categoria e gera relatórios em CSV e JSON.

O exercício reforçou a importância de processos determinísticos, repetíveis e
testáveis.

## Projeto 7 - Aplicação Integrada

Consolidei os conhecimentos em uma aplicação com Streamlit, FastAPI e SQLite.
O dashboard tenta consumir a API HTTP e possui fallback local para continuar
executável durante os estudos.

Esse projeto mostra a evolução de scripts isolados para uma solução organizada
em camadas.

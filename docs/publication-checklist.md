# Checklist de publicação

## GitHub

- [ ] README explica problema, instalação e execução.
- [ ] `requirements.txt` está atualizado.
- [ ] Nenhum banco local, segredo ou arquivo temporário foi incluído.
- [ ] Testes passam em uma execução limpa.
- [ ] Capturas de tela mostram a funcionalidade real.
- [ ] Commit descreve a evolução do projeto.

## LinkedIn

- [ ] Explicar o que foi aprendido.
- [ ] Mostrar uma evidência visual.
- [ ] Informar tecnologias usadas.
- [ ] Incluir GitHub e aplicação publicada.
- [ ] Revisar o texto antes de publicar.
- [ ] Publicar somente depois de estudar e conseguir explicar o projeto.

# Revisão do Projeto 2 - Análise exploratória

## Domínio

`load_data` prepara a base, `build_summary` calcula indicadores e
`create_figures` produz uma evidência visual. O projeto separa cálculo de
apresentação para facilitar testes e reprodução.

## Exercícios

1. Adicionar mediana e desvio padrão do preço.
2. Criar um gráfico de preços por categoria.
3. Escrever uma conclusão baseada em dois valores de `summary.json`.

## Pergunta de domínio

Qual decisão alguém poderia tomar com o relatório que não tomaria olhando apenas
para a tabela bruta?

# Revisão do Projeto 6 - Automação de relatório

## Domínio

O script tem uma entrada, uma transformação determinística (`build_report`) e
uma saída CSV. Essa divisão permite testar a regra sem precisar executar todo o
processo de arquivos.

## Exercícios

1. Exportar também para JSON.
2. Incluir o produto mais vendido por categoria.
3. Rejeitar uma base que não tenha as colunas necessárias.

## Pergunta de domínio

O que torna uma automação repetível e confiável em vez de apenas um script que
funciona uma vez?

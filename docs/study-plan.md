# Roteiro de estudo da trilha

O objetivo desta etapa não é apenas publicar código, mas conseguir explicar
cada decisão técnica com segurança.

## Ordem de revisão

1. Dashboard: Pandas, filtros, métricas e gráficos.
2. Análise exploratória: perguntas, validação, agregações e conclusões.
3. CRUD: SQL, SQLite, transações, validação e testes.
4. API: rotas, schemas, status HTTP e documentação.
5. Machine Learning: features, treino, teste, MAE e R².
6. Automação: entrada, transformação, saída e repetibilidade.
7. Integração: separação entre interface, API e persistência.
8. Engenharia de software: requisitos, refatoração, testes e manutenção.

## Método para cada projeto

- explicar o objetivo em duas frases;
- desenhar o fluxo dos dados;
- executar uma funcionalidade sem consultar o código;
- alterar uma regra e observar o resultado;
- escrever um teste novo;
- fazer uma pequena refatoração;
- preparar uma explicação curta para o LinkedIn.

# Revisão do Projeto 5 - Machine Learning

## Domínio

O projeto transforma preço e categoria em variáveis de entrada e quantidade
vendida em variável-alvo. A regressão estima coeficientes, e MAE/R² ajudam a
avaliar a qualidade da previsão.

## Exercícios

1. Comparar o modelo com a previsão constante pela média.
2. Adicionar uma feature derivada, como faixa de preço.
3. Explicar por que oito linhas são insuficientes para uma conclusão comercial.

## Pergunta de domínio

Por que um R² baixo não deve ser escondido ou substituído por um número mais
bonito?

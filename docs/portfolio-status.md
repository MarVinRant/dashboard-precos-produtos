## Critério para mudar um projeto para "estudado"

- explicar o fluxo principal sem consultar o código;
- executar o projeto localmente;
- completar pelo menos dois exercícios;
- criar ou alterar um teste;
- registrar uma limitação e uma melhoria futura.

## Critério para publicar

O projeto precisa estar estudado, com testes verdes, README revisado,
dependências reproduzíveis, captura de tela e link validado.

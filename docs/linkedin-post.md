# Rascunho para LinkedIn

## Meu primeiro projeto prático com Python e Pandas

Concluí o MVP de um Dashboard de Preços e Produtos, criado como parte da minha trilha prática de estudos.

Neste projeto pratiquei:

- Python e organização em módulos;
- Pandas e DataFrames;
- validação e limpeza de dados;
- cálculo de indicadores;
- criação de gráficos com Plotly;
- construção de uma interface com Streamlit;
- testes automatizados básicos.

A primeira versão utiliza uma base CSV local e já está preparada para receber dados de tabelas HTML com `pandas.read_html`.

O principal aprendizado foi perceber que uma análise de dados não começa no gráfico: ela começa na qualidade, na estrutura e na validação dos dados.

Este é o primeiro projeto de uma sequência que continuará com um sistema de controle financeiro, um aplicativo de tarefas e um painel de indicadores de estudos.

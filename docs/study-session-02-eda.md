# Sessão 2 - Análise exploratória

## Objetivo

Aprender a transformar uma base tabular em perguntas, indicadores e evidências
visuais sem tirar conclusões que os dados não sustentam.

## Conceitos

- média resume o valor central, mas pode ser influenciada por extremos;
- mediana representa o ponto central ordenado;
- desvio padrão indica a dispersão dos preços;
- agrupamentos permitem comparar categorias;
- uma conclusão precisa citar o indicador que a sustenta.

## Exercício implementado

O resumo do projeto agora calcula `preco_mediano` e `desvio_preco`, com testes
para verificar os valores em uma base conhecida.

## Tente explicar

1. Quando a mediana é mais informativa que a média?
2. O que significa um desvio padrão alto nesse contexto?
3. Por que um gráfico não substitui a validação dos dados?

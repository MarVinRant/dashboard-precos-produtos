# Projeto 2 - Análise exploratória de produtos

Análise reproduzível da base de produtos usada no dashboard. O objetivo é
transformar dados brutos em perguntas, métricas, visualizações e conclusões.

## Perguntas

- Quais categorias concentram mais vendas?
- Quais produtos têm maior preço?
- Existe diferença relevante entre preço e volume vendido?
- Há dados ausentes ou inconsistentes?

## Executar

```bash
pip install -r requirements.txt
python analysis.py
```

Os resultados são gravados em `outputs/summary.json` e `outputs/figures/`.

# Projeto 3 - Sistema de estoque com SQLite e CRUD

Aplicação de estudo para praticar Python, SQL e o ciclo CRUD: criar, consultar,
atualizar e excluir produtos de um estoque local.

## Executar

```bash
pip install -r requirements.txt
streamlit run app.py
```

O banco `estoque.db` é criado automaticamente no primeiro uso.

# Projeto 5 - Previsão de vendas

Modelo introdutório de Machine Learning com NumPy para estimar a quantidade vendida a
partir do preço e da categoria do produto. O foco é aprender o fluxo completo:
preparar dados, separar treino e teste, treinar, avaliar e interpretar.

## Executar

```bash
pip install -r requirements.txt
python model.py
```

O resultado da avaliação será salvo em `outputs/metrics.json`.

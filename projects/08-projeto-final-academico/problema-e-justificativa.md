# Problema e justificativa

Pequenas operações comerciais precisam consultar produtos, preços e volume de
vendas sem depender de planilhas espalhadas ou registros manuais. A solução
proposta organiza esses dados em uma aplicação simples, reproduzível e
publicável.

O projeto é relevante academicamente porque reúne programação Python, análise
de dados, banco SQLite, API REST, interface web, testes e documentação de
engenharia de software em um único fluxo.

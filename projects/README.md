# Trilha de projetos - Python e Engenharia de Software

Esta pasta reúne os projetos desenvolvidos a partir dos conteúdos da faculdade.
Cada projeto terá código, testes, documentação e uma etapa de publicação própria.

## Ordem de desenvolvimento

1. `01-dashboard-precos` - piloto concluído na raiz do repositório.
2. `02-analise-exploratoria` - análise reproduzível de dados de produtos.
3. `03-estoque-crud` - aplicação com SQLite e operações CRUD.
4. `04-api-produtos` - API REST com FastAPI.
5. `05-machine-learning` - modelo de previsão usando dados de produtos.
6. `06-automacao-relatorio` - geração automatizada de relatório.
7. `07-aplicacao-integrada` - união de banco, API, análise e interface.
8. `08-projeto-final-academico` - documentação formal e apresentação da solução.

## Critério de conclusão

Um projeto só será considerado concluído quando tiver implementação funcional,
testes mínimos, README, instruções de execução, evidências e revisão do conteúdo.
